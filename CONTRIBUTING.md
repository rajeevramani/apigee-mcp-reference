# Contributing

Contributions that improve portability, verification, documentation, or compatibility with current Apigee MCP behaviour are welcome.

## Before opening a pull request

1. Keep examples customer-neutral and use fictitious names and payloads.
2. Do not include tenant IDs, hostnames, IP addresses, credentials, screenshots, or customer architecture details.
3. Run:

   ```bash
   python3 scripts/verify.py
   ```

4. Explain whether the change reflects official documentation, behaviour you reproduced in your own environment, or an architecture recommendation.
5. Keep generated and source copies of each OpenAPI document aligned.

By contributing, you agree that your contribution is licensed under Apache License 2.0.
